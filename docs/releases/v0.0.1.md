# CloudCDN 0.0.1

## Highlights ⭐️

* **Edge asset delivery**: CloudCDN serves tenant assets through Cloudflare
  with transforms, signed URLs, cache controls, responsive variants, and
  operational health checks.
* **Dashboard and automation**: The dashboard covers asset discovery,
  uploads, insights, and account administration, while the MCP server
  exposes the platform to agent hosts.
* **Security controls**: Authentication, scoped keys, rate limits, audit
  logs, bot defenses, strict browser policies, and dependency scanning
  protect the public and control-plane surfaces.
* **Release baseline**: Dependency audits are clear, CI dependencies are
  immutable, and the unit, coverage, responsive-asset, and visual
  regression gates pass from a clean install.
