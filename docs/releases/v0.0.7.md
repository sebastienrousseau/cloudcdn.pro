# CloudCDN 0.0.7

## Highlights ⭐️

* **Assets work on every domain again**: images, icons and CSS from
  cloudcdn.pro load on other sites. Two Cloudflare zone settings were
  blocking them (a `same-site` resource policy and Hotlink Protection);
  both are fixed and documented in `docs/cloudflare-zone.md`.
* **Live guard against zone drift**: a daily and post-deploy check
  requests real assets as a cross-site browser and fails if the edge
  stops serving them.
* **Security upgrades**: @hono/node-server 2.1.3+, qs 6.16.1+ and
  @modelcontextprotocol/sdk 1.32.2 in the MCP server; minimatch 11.0.1+
  in the site.
* **Linting with complexity ceilings**: ESLint now runs in CI with
  per-function ceilings and a baseline that may only shrink.
