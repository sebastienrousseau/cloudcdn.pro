# CloudCDN 0.0.5

## Highlights ⭐️

* **Catalogue Refresh**: Synchronises newly published owned repositories and
  updates package versions across npm, crates.io, PyPI, and GitHub releases.
* **Dependency Upgrades**: Upgrades wrangler to 4.146.0, Skeletonic Stylus to
  3.0.0, and Vitest suite to 5.0.3.
* **Security Hardening**: Resolves all audit vulnerabilities with targeted
  overrides for `@parcel/watcher`, `sharp`, and `source-map-js`.
