# CloudCDN 0.0.8

## Highlights ⭐️

* **SVG sanitiser fix (GHSA-83v7-xc9g-5frf)**: uploaded SVGs no longer keep a `javascript:`, `vbscript:` or unsafe `data:` link when the attribute value is unquoted. Quoted values were already cleared.
* **Simpler sanitiser code**: the attribute scanner is split into small helpers that meet the complexity ceilings, and the complexity baseline shrinks by three entries.
