# CloudCDN 0.0.6

## Highlights ⭐️

* **One canonical host**: `cloudcdn-pro.pages.dev` now redirects to
  `https://cloudcdn.pro` with its path and query, so the site and API are
  no longer served twice.
* **MCP server under the author's scope**: It is published as
  `@sebastienrousseau/cloudcdn-mcp` from 0.1.1, declares the repository's
  `Apache-2.0 OR MIT` licence and reports its real version to clients.
* **Security upgrades**: undici 7.30.1, happy-dom 21.0.4 and vite held at
  patched versions in the site; zod 4.6.7, fast-uri 3.1.9, body-parser
  2.4.0, proxy-addr 2.0.8 and @modelcontextprotocol/sdk 1.32.1 in the MCP
  server, with every advised package constrained so no affected version
  can install.
