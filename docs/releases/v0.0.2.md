# CloudCDN 0.0.2

## Highlights ⭐️

* **Complete GitHub catalogue**: The `/dist/` marketplace includes every
  owned public repository that has a published latest GitHub release.
* **Current release details**: GitHub release tags are normalized for display,
  and cards link to downloadable assets or the repository release page.
* **Automatic discovery**: The weekly refresh discovers newly published
  repositories before resolving versions from GitHub, npm, crates.io, and
  PyPI.
* **Stable image automation**: Visual test snapshots no longer trigger image
  conversion, and the workflow uses the locked dependency graph.
