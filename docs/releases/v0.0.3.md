# CloudCDN 0.0.3

## Highlights ⭐️

* **Clear product positioning**: Search and social metadata describe CloudCDN
  as a self-hosted CDN and digital asset management platform.
* **Rich link previews**: Deterministic branded artwork supports Open Graph,
  Twitter cards, and the GitHub repository preview.
* **Measurable discovery**: Every localized homepage has reciprocal sitemap,
  canonical, and Open Graph URL metadata. A search runbook covers sitemap
  registration and the target query groups.
* **Accurate trust signals**: Documentation avoids volatile counts and states
  the Apache-2.0 or MIT licensing choice consistently.
