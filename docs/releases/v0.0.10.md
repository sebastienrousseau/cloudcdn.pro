# CloudCDN 0.0.10

## Highlights ⭐️

* **Patched MCP server dependencies**: the MCP server now requires hono 4.13.16 and @hono/node-server 2.1.8 or later, which fix seven published advisories.
* **Fresher marketplace**: the catalogue lists newly published repositories and their latest registry versions.
* **Toolchain refresh**: Playwright, Tailwind CSS, Vitest, Wrangler and the CI actions move to their current releases.
